## Deliberate boundaries

- Image publication alone does not change the VM. Source-service merges publish images; reviewed infra develop merges promote the selected manifest automatically after activation.
- Existing host topology/configuration, secrets, Caddy certificate volumes, broker data and shared database schema are preserved. Config/schema adoption is separate from automatic image rollout.
- Current candidate schema evidence is deliberately `PENDING`, and the host example is unapproved. Do not manufacture migration provenance to enable a pipeline.
- A provisioned staging deployment exists; this implementation has not deployed or configured a production host. Environment/branch protections cannot be established merely by writing YAML.
- Offline tests verify failure recovery; they are not a live rollback rehearsal or database restore. The owner deferred the live rehearsal.
- Health/HTTP success is not proof of payment, email delivery, QR, task/order flow, realtime events or complete endpoint coverage.
